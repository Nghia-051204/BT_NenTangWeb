05 Fade-in khi Scroll

↓ Cuộn xuống để xem các card xuất hiện lần lượt

✦

Opacity 0 → 1

Từ hoàn toàn trong suốt đến hiển thị đầy đủ theo trục Y.

◈

translateY 20px → 0

Kết hợp dịch chuyển nhẹ lên trên tạo cảm giác "nổi lên".

◇

animation-fill-mode

both giữ trạng thái cuối, tránh flash trước khi animation chạy.

⬡

animation-timeline

CSS hiện đại dùng view() để trigger chính xác khi vào viewport.

✿

Stagger Delay

Mỗi phần tử delay thêm 100ms tạo hiệu ứng cascading mượt mà.

◉

CSS-Only

Không cần Intersection Observer hay JavaScript — thuần CSS.

CSS — Fade-in Scroll

@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.fade-in-item {
  animation: fadeInUp 0.6s ease both;
  animation-delay: var(--delay, 0s);

  /* Modern CSS — trigger on scroll */
  animation-timeline: view();
  animation-range: entry 0% entry 30%;
}

↑ animation-timeline: view() được hỗ trợ Chrome 115+, Firefox 114+. Fallback: animation chạy khi load với delay.
